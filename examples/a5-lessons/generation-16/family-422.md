In an A5 Catlass TLA vector-function body, a dynamic `if/elif/else` on a host-bound selector rejects at preprocessing with `SyntaxError: dynamic Tla if requires variables used after the branch to be initialized before the if: <name>`. Bind that name before the branch (e.g. `gi = zero` on a `tla.Float32(0.0)` constant) and keep every branch assigning it; the change is local to the kernel body and no launcher or synchronization change is required. Do not treat the initializer as a value: it is overwritten in all branches, so pick zero. Separately, when implementing overflow-safe sigmoid identities with `tla.where`, never use a nonzero constant such as `one` as the filler operand — `tla.where(cond, val, one)` yields one (not zero) on the false path, which silently corrupts the algebra while still lowering. Derive the bounded pieces from min/max built against zero, e.g. `mn = tla.where(xi < zero, xi, zero)`, `mx = tla.where(zero < xi, xi, zero)`, `w = tla.exp(mn - mx)`, then write selection 1 as `exp(mn) / (one + w)` and selection 2 as `one - exp(zero - mx) / (one + w)`.
