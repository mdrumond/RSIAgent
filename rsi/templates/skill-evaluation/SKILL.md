# Evaluate before promotion

## Contract
Run isolated paired held-out tasks with identical inputs, memory and budgets for incumbent and candidate. Rank workflow compliance, correctness, recovery then performance. Reject violations and correctness regressions; keep the incumbent for inconclusive evidence. Preserve all traces and negative outcomes. Do not train on held-out results.

## Evidence
Use instrumented skill reads and cite section references. Link decisions to retrieved records and observable action receipts. Exposure is not reading; citation is not demonstrated application. Return structured results and artifact references to the host controller, which owns transitions and acceptance.

## Time accounting
Respect remaining parent and step allocations across resume. Charge thinking, retrieval, compilation, execution, profiling, failures, warmups and synchronisation to actor time. Exclude actor setup and remote data copy only for their measured intervals; transfers cannot hide overlapping active work. Preserve raw timings and separate wall time. Do not label compilation as setup or reset consumed budget.

## Learned guidance
RSI may populate evidence-linked reusable guidance here. Preserve provenance, negative results, applicability and corrections. Do not copy user-wide installed CPL skills into this output bundle.
